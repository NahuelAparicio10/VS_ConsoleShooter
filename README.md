GOAL

Create a game using the Visual Studio console as part of a first-year university project. 

How I resolved it 

I designed a simple shooting game where the player has to kill static enemies on a board. I built the core game loop, implemented player movement and shooting mechanics, and added additional features such as ranking with score points.

What I learned 

I gained a solid understanding of game loops, game logic, and how to structure gameplay systems in C++.
